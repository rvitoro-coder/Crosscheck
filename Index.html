CROSSCHECK

Functional prototype
Guess the hidden five-letter word. After each guess you get Letters · Placed. “Letters” counts shared letters one-to-one, including duplicates. “Placed” counts exact-position matches.
Six guesses. Prototype word list validates accepted guesses.
Prototype integrity

The secret is selected once per game and stored in game state. Scores are generated only by score(answer, guess). The UI never supplies scores manually. Before each render, the program recomputes the entire history and throws an error if any stored score differs.
